\# AI Smart Cane



AI-based smart cane project for visually impaired users.



\## Raspberry Pi Functions



\- YOLO object detection

\- ToF obstacle detection

\- PCA9685 vibration motor control

\- BLE communication

\- Battery monitoring



\## Project Structure



\- `main/` : Integrated main program

\- `vision/` : Camera and YOLO object detection

\- `tof/` : ToF sensor control

\- `motor/` : Vibration motor control

\- `ble/` : Bluetooth communication

\- `battery/` : Battery monitoring

\- `models/` : Model information
